# Grupo-43---Projeto Integrador: Desenvolvimento de Sistemas Orientados a Dispositivos móveis e Baseados na Web

## ReciclaBairro

### Passo a passo de como acessar o site

**Requisitos:**

- [Node.js](https://nodejs.org/) versão 20 ou superior
- [Git](https://git-scm.com/) para clonar o repositório

Em um terminal (como o PowerShell), insira os seguintes comandos na ordem apresentada:

```bash
git clone https://github.com/Grupo43-star/Grupo-43---Projeto-Integrador.git
cd Grupo-43---Projeto-Integrador/frontend
npm install
npm run dev
```

Por último, cole o link abaixo no seu navegador e o site estará disponível:

```
http://localhost:5173/
```
